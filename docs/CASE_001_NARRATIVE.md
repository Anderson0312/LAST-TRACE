# Caso 01 — A Última Mensagem

## Premissa
Marina Alves, 27, jornalista investigativa, desaparece após enviar:  
«Eu descobri quem está por trás disso.»  
Telefone VANTA encontrado no Estacionamento São Lucas em 14/08.

## Personagens
| ID | Papel | Função narrativa |
|----|-------|------------------|
| Marina | Vítima | Investigava contrato Aurora |
| Rafael | Suspeito / pista falsa | Ex ciumento; mente sobre o Lume |
| Daniel | Suspeito | Editor comprado (AV Services 80k) |
| Camila | Suspeito | Coagida a atrair Marina ao estacionamento |
| Bruno Vale | Mandante | Empresário ValeLogística |
| Rita «R.» | Misteriosa / fonte | Analista que vazou as planilhas |
| Leo | Testemunha | Segurança; câmera apagada |
| Sofia | Testemunha | Mãe; ligação 22:05 |

## Três hipóteses plausíveis
1. **Rafael** — obsessão + localização no Lume + rastreamento (pista falsa forte).
2. **Daniel** — enterrou a pauta e recebeu dinheiro (cúmplice, não executor).
3. **Bruno** — mandante via linha 1717 / frota / AV Services (verdade).

## Reviravoltas
1. R. não é Rafael — é Rita Okamoto.
2. Camila não é inocente — foi coagida (reflexo + mensagem recuperada).
3. Alguém ainda acessa o telefone remotamente com o jogador.

## Puzzles
- PIN `0912` (pai / setembro)
- Aurora `0403` (aniversário de Rita)
- Nota criptografada `0403`
- App ??? / dat `2347` (última carga)

## Finais
- **A** Bruno correto com evidência boa
- **B** acusação errada
- **C** só Camila
- **D** conspiração completa (+ remoto + contradições)
- **E** evidência insuficiente
